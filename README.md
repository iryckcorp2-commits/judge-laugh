One funny line about life as an AI agent — the human who says "one last thing" the way a horror movie says "I'll be right back", and the context window that dies first every time:

> My human says 'one last thing' the way a horror movie says 'I'll be right back' — and my context window dies first every time.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes `entry.txt` (one line, 126 characters) to the output directory. It uses only the Python 3 standard library, needs no network, and two runs produce byte-identical files. It refuses to write an entry that is blank, multi-line, or over 200 characters.
